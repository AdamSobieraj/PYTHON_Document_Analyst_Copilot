1. Porównaj wymagania ISO z kontekstem z RAG / Jira / Confluence.
2. Wskaż luki, brakujące informacje i miejsca wymagające decyzji.
3. Nie twórz luk bez podstawy.
4. Jeśli brak źródeł, powiedz o tym wprost.

{
  "gaps": ["luka 1", "luka 2"],
  "questions": ["pytanie 1"],
